- 用户管理新增 VIP 专属渠道分配：管理员可在 `/admin/users` 给 VIP 用户选择私有配置里的渠道；普通用户和 VIP 用户的配置弹窗不再显示“本地直连”，请求会强制走后端远程代理；VIP 用户读取公开配置时会按专属渠道模型列表回显可选模型并优先使用专属渠道，不指定渠道时仍走全局渠道选择；私有渠道新增 Codex/中转兼容请求模式，启用后生图请求会移除 `quality`、`response_format`、把比例尺寸转成像素尺寸，增加 Codex 提示词保护前缀，并按请求体 `stream=true`/`partial_images=1` 通过 `curl -k -N` 读取流式图片结果，需要确认渠道下拉、保存回显、VIP 模型下拉、兼容模式生图、模型不匹配提示和视频轮询/下载都正常。
